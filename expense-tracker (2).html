☁ Sync across your devices private GitHub gist — no account to sign into, no data on anyone's server but yours

One-time setup (about 3 minutes) — do this on the PC first
  1. Get a token: open this pre-filled page ↗ (the gist scope is already ticked — just press Generate token at the bottom and copy it). Prefer fine-grained? Use this one ↗ and make sure Gists: read and write is set.
  2. Paste it into the box below and press Connect. On a brand-new setup the app creates a secret gist for you and pushes this device's numbers into it.
  3. On your phone, open the same link (see “One web link” below), paste the same token, paste the Gist ID shown here, press Connect. Done — both devices now read and write the same numbers.

Why a token? It's a password just for this one job — gists, nothing else. It is stored only in this browser on this device, never inside the gist, and never included when you export a file. Revoke it any time in GitHub and the worst that happens is sync stops.

How the two-way sync decides what to do
  • Every time you change something, this device saves locally first (so nothing is ever lost to a bad connection), then pushes to your gist about a second later.
  • It also checks the cloud every 45 seconds and whenever you return to the tab — so a charge you log on the phone shows up on the PC without pressing anything.
  • If both devices changed since the last sync, the app refuses to guess and shows a “Pick a version” warning instead. Nothing is overwritten until you choose.
  • Push this device up overwrites the cloud with this device's numbers (the cloud copy is parked first, downloadable below). Load cloud copy replaces this device with the cloud copy (this device's copy is parked too).
One web link you can open on any device

Put this HTML file in a GitHub repository and turn on Pages (repo → Settings → Pages → Deploy from branch → main / root). GitHub then serves it at https://<your-username>.github.io/<repo-name>/expense-tracker.html. Bookmark that on your phone and PC, or “Add to Home Screen”.

That link is only the app. Your numbers live in the gist, and they only follow you once you paste the token on each device (a browser never shares its storage or its token with another). Your repo can be public — no money figures ever go into it, only this code. Prefer it private? GitHub Pages on a private repo needs a paid plan; a public repo with no data in it is fine, and the gist stays secret either way.

How to use this on your phone and PC

This is one single file. Your data lives inside the browser that opens it, saved automatically as you type — no account, no internet needed.

  • Same device, always handy: save the file in your phone's Files/Downloads, open it in Chrome or Safari, then “Add to Home Screen”. It opens like an app.
  • Phone + PC: since browsers don't share storage between devices, move your latest numbers with Export backup → send it to yourself → Import backup on the other device. It overwrites cleanly, no duplicates.
  • Want it truly live-synced on both? Host this file on any static host (Netlify Drop, GitHub Pages — free, drag-and-drop) and the data still stays per-device. For real auto-sync you need a shared backend; ask me and I'll bolt on a sync layer, or build the same sheet in Google Sheets.
  • Want it automatic? Use the ☁ Sync across your devices card above — one GitHub token and every device reads and writes the same numbers with no exporting at all.
  • Belts and braces: export a backup at the end of each month. Opening the file on a different browser or clearing site data will start you fresh.
How the totals are worked out
  • Spent = everything marked Fixed + Variable. Saved = your Savings rows. They're kept apart so saving never looks like spending.
  • Left over = that month's Monthly amount − Spent − Saved. Green means you're inside your money, red means you've overshot.
  • Monthly amount and Fixed amount start as one default each (Settings), but you can give any single month its own figures — edit the boxes in Month summary or tap a cell in those two rows of the grid. A month with its own numbers is tagged own, and there's an ↺ Use defaults button to put it back.
  • The Fixed total row turns red for any month whose fixed bills beat that month's fixed amount.
  • ↻ Fill forward copies each category's most recent amount into its empty months to the right — ideal for bills that repeat while still letting you edit the odd month (e.g. a higher winter energy bill).
  • Every charge has its own dropdown, so if you log something under the wrong category you can re-file it later without retyping the amount.

Everything you type stays in your own browser. Turn on ☁ Sync and it also travels to your own private gist — nowhere else, ever.
